A dependency-free, cursor-based re-implementation of marked 18.1.3's Markdown parser that renders byte-for-byte identical HTML, faster: sticky regexes at a cursor instead of repeated string slicing, cheap block pre-filters, and a fast plain-text scan for inline runs.

## Run it

```sh
node --experimental-strip-types main.ts
```
